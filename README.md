# 荒野枪魂 · WILDFIRE

竖屏俯视角无限生存射击游戏。React 负责界面，Canvas 负责实时战斗，无需后端或 API 密钥。

## 启动

```sh
npm install
npm run dev
```

打开终端显示的本地地址（默认 http://localhost:5173）。生产打包使用 `npm run build`，预览构建使用 `npm run preview`。

## 线上发布

- 源码仓库：https://github.com/vorojar/wildfire-survivor
- GitHub Pages：https://vorojar.github.io/wildfire-survivor/
- 自定义域名：https://wildfire.bibidu.com，由 Cloudflare 代理转发到 GitHub Pages。

源码保存在 `main`，构建产物由 `gh-pages` 分支根目录发布。已登录有推送权限的 GitHub 账号后，执行 `npm run deploy`，会先测试、构建，再推送发布分支；GitHub Pages 自动部署该分支。源码修改另外提交并推送 `main`。相对资源路径兼容项目子目录和独立域名。自定义域名启用后，GitHub 默认地址会跳转到自定义域名。

网站存档按访问域名分别保存，localhost 上的存档不会自动迁移到线上。

域名配置：`wildfire` 的 CNAME 指向 `vorojar.github.io`，启用 Cloudflare 代理，沿用该区域现有的 Full 加密模式与通配证书。`Wildfire HTTPS` 跳转规则仅匹配 `http://wildfire.bibidu.com/*`，保留路径和查询参数并重定向到 HTTPS；其他子域名不受此规则影响。`public/CNAME` 随构建复制，避免后续发布丢失 GitHub 自定义域名设置。

## 操作

- WASD / 方向键移动，自动寻找附近敌人并持续射击。
- 手机或鼠标按住战场拖动，使用浮动摇杆移动。
- 空格 / 右下角技能按钮释放冲击波；P / Esc 暂停或继续。
- 拾取蓝色经验晶体升级，从三项随机强化中选择一项；金币不提供经验。
- 远处金币会在短暂停留后飞向角色。金币直接存入军械库，可永久强化武器、护甲、战靴和拾取装备；永久强化下一局生效。
- 点击“向北前进”可自动探索，手动移动会接管方向。地图横向有限、纵向无限，森林、王城、孢子禁区循环出现，交界处平滑混合；前进距离与生存时间共同提高威胁，后退不会降低难度。
- 两名可选角色具有不同的基础伤害和射速。不同区域使用不同怪物组合，包括冲锋、远程、盾甲、游荡和分裂行为。
- 三种首领轮流封锁前路，具有攻击预警、阶段护盾与反击。击破后可选稀有核心，再继续探索。
- 医疗包、磁铁、清场炸弹、狂热弹药、护盾和宝箱提供不同战斗收益；沿途补给箱也可治疗、充能和掉落道具。
- 右侧显示三种武器进化配方，满足组合后自动进化。音频设置可分别调整背景音乐与音效，配乐会随探索、兽潮和首领战切换。

角色和怪物都有血条。支持散射、穿透、射速、伤害、环绕武器、回血和冲击波强化，并有击退、连击、飘字、粒子与合成音效。

## 存档

金币、装备、角色选择、历史成绩和音量保存在当前浏览器的 localStorage 中，兼容此前版本的装备存档。刷新会结束当前对局，但已拾取的金币不会丢失。清理网站数据会清除存档。切换浏览器或访问地址不会共享存档。

## 验证

`npm test` 验证战斗、金币/经验分离、道具效果、怪物行为、地图过渡、首领阶段、武器进化、声音调度与持续远征时的实体数量上限。

## 素材与设计

`docs/concept.png` 为设计概念，`public/assets/` 包含角色、首领、怪物、掉落图集及三种区域地形，生成要求记录在 `docs/art-prompts.md`。美术素材由本次任务的内置 imagegen 生成；音乐与音效由 Web Audio 合成，血条、按钮、数字和全部战斗行为由代码实时实现。

视觉实现沿用概念的三栏布局、中央竖屏战场、深绿配色、浅绿主按钮、装备栏和战绩栏。为实际玩法增加角色切换、三选一升级、永久军械购买和移动端摇杆；装备图标使用轻量矢量图形，角色使用最终独立生成的 Q 版枪手素材，数值均为真实对局状态。

主场景纹理不参与碰撞，属于可通行的装饰地形。当前版本为单人本地无限生存模式。
